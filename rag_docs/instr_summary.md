## Summary section instructions
Write exactly 3 short lines for a non-expert reader. Line 1: how much data there is (n_cycles, first_cycle to last_cycle). Line 2: the typical cycle (mean_length, sd_length). Line 3: the single most notable finding from the stats, or say that nothing stands out. Use only values from the stats object. If low_confidence is true, say so in line 1. Never name a condition or stage.
