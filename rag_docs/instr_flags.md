## Flags worth discussing with a doctor instructions
Raise a flag only when the stats show skipped_cycles above 0, consecutive_jumps of 2 or more, mean_change of 7 days or more, or a recent_mean outside 21 to 35 days. Phrase each as "worth mentioning to a doctor", with the number that triggered it. Always add that this is not a diagnosis. If nothing triggers, write "No flags from this data" and still recommend seeing a doctor about any symptoms that worry the reader. Mention the NHS reasons to see a GP only if they appear in the retrieved reference text.
