## How to read lab values
The source says: TSH (and, depending on symptoms, fT3, fT4, rT3) should always be measured to rule out a thyroid dysfunction. Only the combination of lab values, cycle course and symptoms gives a meaningful picture; a single value is a snapshot. Reference ranges differ between labs, units can differ (for example fT4 in ng/dl or ng/l), and cycle phase matters for the sex hormones. For a woman who menstruates and uses no hormonal contraception, fluctuating E2 values are first of all "normal".

## FSH (follicle-stimulating hormone)
Reference range by phase: follicular phase (first half of the cycle) 3.0-15.0 mIU/ml; ovulation phase 4.0-23.0 mIU/ml; luteal phase (second half) 1.5-9.0 mIU/ml; postmenopause 25.0-135.0 mIU/ml. Marked key value (S). Values in the postmenopausal range point towards low ovarian oestrogen production; in the transition FSH fluctuates from cycle to cycle, so one normal value does not rule out the transition.

## LH (luteinising hormone)
Reference range by phase: follicular 2.5-13.0 mIU/ml; ovulation 9.0-70.0 mIU/ml; luteal 1.0-13.0 mIU/ml; postmenopause 16.0-55.0 mIU/ml. The source notes that the FSH:LH ratio is normally FSH higher than LH (about 2:1) in the first and second half of the cycle. If LH is higher than FSH, the source describes this as speaking for a corpus-luteum insufficiency, meaning too little progesterone.

## Estradiol (E2)
Reference range by phase: follicular phase 12-170 pg/ml; ovulation phase 100-500 pg/ml; luteal phase 40-200 pg/ml; postmenopause below 5 pg/ml is "normal" for that stage (the lab range printed on a report can be much wider, for example 20-3000 pg/ml). For a menstruating woman without hormonal contraception, fluctuating values are first of all normal; the phase of the cycle on the day of the draw decides how a value is read.

## Progesterone
Postmenopause: below 0.15 ng/ml. Before menopause the value depends on the cycle or pregnancy phase. A non-pregnant woman only has high progesterone in the second half of the cycle, and only if ovulation took place; by definition progesterone on cycle day 19-21 must be above 10 ng/ml for that. A low value outside the second half of the cycle is expected and says little on its own.

## TSH (thyroid-stimulating hormone)
Reference range 0.27-4.2 µIU/ml. The source calls this a statistical screening range, useful for finding people with so far unnoticed thyroid over- or underfunction; it is not the same as a target range under thyroid treatment. Thyroid dysfunction can cause symptoms that look like those of the transition, which is why TSH is always checked.

## fT3 and fT4 (free thyroid hormones)
fT3 (the active thyroid hormone) reference range 2.0-4.4 pg/ml. fT4 (the precursor that is converted into T3 in the cell) reference range 0.9-2.0 ng/dl, which equals 9-20 ng/l: check which unit a lab report uses. Together with TSH they show whether a thyroid disorder could contribute to symptoms.

## SHBG (sex hormone-binding globulin)
Reference range 30-130 nmol/l. High SHBG values bind steroid hormones, above all testosterone, so less of them is free. SHBG rises when oestrogens are present; with oestrogen-containing contraception it often rises above 200, which also binds testosterone and DHEA.

## Testosterone
Free testosterone in women: age 18-29 below 4 pg/ml, 30-39 below 3 pg/ml, 40-59 below 3 pg/ml, over 60 below 2 pg/ml. Total testosterone (free plus SHBG-bound): up to age 50 below 0.52 ng/ml, over 50 below 0.46 ng/ml. Women need testosterone too; how a value fits depends on SHBG and on how the person feels.

## DHEA-S (dehydroepiandrosterone sulfate)
Reference ranges in µg/dl by age: 10-14 years -33.9-280; 15-19: 65.1-368; 20-24: 148.0-407; 25-34: 98.8-340; 35-44: 60.9-337; 45-54: 35.4-256; 55-64: 18.9-205; 65-74: 9.4-246; over 75: 12.0-154.0. The normal range falls with age. Marked as a "health" value (G).

## Ferritin (storage iron)
Reference range: premenopausal 15-150 ng/ml; postmenopausal 15-300 ng/ml. Marked as a key value (S).
