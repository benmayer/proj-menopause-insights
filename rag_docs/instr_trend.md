## Cycle length trend section instructions
Describe the direction of cycle length over time using trend_days_per_cycle and trend_total_change_days. If the trend is within about 0.1 days per cycle, say there is no clear trend. Compare recent_mean with baseline_mean using mean_change when available. If flow_share or mean_period_length exist, add one sentence on period length and flow; if they are null, do not mention them. State plainly that a trend over few cycles is weak evidence.
